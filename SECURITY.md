# Security Policy

## Supported Versions

We provide security updates for the following versions of LLM Client Go:

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < v0.1  | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it responsibly.

**Please DO NOT open a public issue or discussion for security vulnerabilities.**

Instead, please report security issues via:
- **Email**: Send details to [wkqco33@gmail.com](mailto:wkqco33@gmail.com) with the subject `[SECURITY] LLM Client Go Vulnerability Report`.
- **GitHub Private Vulnerability Reporting**: If available, use the "Report a vulnerability" tab on GitHub.

### What to Include in Your Report

- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction steps or a minimal proof of concept (PoC).
- Any proposed remediation or patch, if available.

### Our Response Process

1. **Acknowledgment**: We will acknowledge receipt of your report within 48 hours.
2. **Assessment**: We will investigate and assess the severity and impact.
3. **Remediation**: A fix will be developed, tested, and released as a security patch.
4. **Disclosure**: Once resolved, we will publish a security advisory crediting your discovery (unless you request anonymity).
